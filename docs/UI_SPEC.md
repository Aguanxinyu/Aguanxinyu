# 今日待办：页面与交互规格

| 项目 | 内容 |
| --- | --- |
| 版本 | 1.2 |
| 状态 | 已确认 |
| 确认日期 | 2026-08-25 |
| 风格 | 纸感底色、宋体品牌字、青绿强调；底栏日历按日浏览；本周回顾见独立页 |

本文继承 [`PRD.md`](./PRD.md) 的信息架构和产品规则；周报 AI 完整口径见 [`WEEKLY_REVIEW_MVP.md`](./WEEKLY_REVIEW_MVP.md)。如交互方案改变产品行为，应先更新 PRD / 周报 MVP 文档，再同步本文。

## 1. 设计原则

- 首页优先回答“这一天要做什么”，默认落在今天。
- 底部日历栏可切换任意日期（含过去），查看当天安排。
- 创建简单待办只要求输入标题；快速创建默认落到当前选中日期。
- 高级字段按需展开，不阻塞快速创建。
- 状态主要通过文字、图标和小面积色彩表达，不使用大面积警示色。
- 所有页面都提供加载、空、错误和离线状态。
- 支持系统字体放大，核心内容不依赖固定高度。
- 点击区域不小于微信小程序建议的可操作尺寸。
- 动画只用于反馈状态变化，不影响完成任务。

## 2. 设计令牌

### 2.1 色彩

| 用途 | 色值 |
| --- | --- |
| 主色（青绿） | `#0F766E` |
| 主色浅背景 | `#D9F3EF` |
| 页面背景 | `#F3EFE6` |
| 内容浅底 | `#FFFDF8` |
| 主文字 | `#10243A` |
| 次文字 | `#3D556E` |
| 边框 | `rgba(16, 36, 58, 0.08)` |
| 危险 | `#B42318` |
| 警告 | `#B45309` |

优先级：

- 高：玫红短标签。
- 中：琥珀短标签。
- 低：绿色短标签。

禁止仅依靠颜色传达完成、错误或优先级；同时使用文字或图标。

### 2.2 尺寸

- 页面水平边距：14px（约 28rpx）。
- 列表行最小高度：约 59px。
- 按钮圆角：4px（约 8rpx）。
- 底栏日历日格：约 43×48px。
- 图标与文字间距：8px。

### 2.3 层级

- 页面使用纸感渐变底，避免纯平单色。
- 任务列表默认不用卡片容器，仅用分割线组织。
- 快速创建与日历栏为底部交互容器，可使用浅底与细边框。
- 月历使用底部弹层；遮罩压暗页面。

## 3. 全局导航

底部导航：

1. 待办。
2. 清单。
3. 我的。

“新建待办”通过首页右上「写」按钮或底栏快速创建进入；不是独立 Tab。

## 4. 待办首页

### 4.1 默认布局

```text
┌──────────────────────────┐
│ 今日待办              写 │
│ 8月21日 · 星期五          │
│ 今天 · 3 项安排           │
│                          │
│ ○ 提交项目资料    高 10:00│
│ ○ 购买生活用品    中 18:30│
│                          │
│ ┌ 记到这一天…      添加 ┐ │
│ │ 按日查看   展开整月    │ │
│ │ 日 一 二 三 四 五 六   │ │
│ │ 16 17 18 19 20 21 22  │ │
│ └──────────────────────┘ │
│ 待办        清单       我的 │
└──────────────────────────┘
```

### 4.2 页面组成

- 顶部：品牌「今日待办」、选中日副标题、当日标题与安排数、「写」进入详情编辑。
- 中部：当前选中日的任务列表（含已完成）；无日期任务只出现在「今天」。
- 底栏：快速创建 + 一周日历条；「展开整月」打开月历弹层。
- 底部 Tab：待办 / 清单 / 我的。

空状态文案随选中日变化：今天提示写下第一件事；其他日期提示该日没有记录。

### 4.3 日历栏与按日浏览

- 默认展示选中日所在周（周日为一周起点，Asia/Shanghai）。
- 点选某一天：列表切换为该日安排；快速创建与「写」默认写入该日。
- 「展开整月」：底部弹层显示月网格，可翻月、点选历史/未来日期，「回到今天」一键复位。
- 数据：`GET /v1/tasks?dueOn=YYYY-MM-DD` 拉取当日任务（含已完成）；今天仍可用全量列表刷新。

### 4.4 任务行

任务行包含：

- 左侧圆形完成按钮。
- 标题（单行省略）。
- 优先级短标签与截止时间摘要。
- 右侧更多（⋯）；长按也可打开操作。

交互：

- 点击标题区域：进入任务详情。
- 点击完成按钮：切换完成状态。
- 长按 / ⋯：移入回收站。

### 4.5 筛选（后续）

首版以日历日切换为主。清单、标签、优先级等高级筛选可后续以弹层补齐。

## 5. 快速创建

```text
┌──────────────────────────┐
│ 新建待办              保存 │
│                          │
│ 需要做什么？              │
│ ──────────────────────── │
│                          │
│ 📅 日期        未设置      │
│ ⏰ 时间与提醒   未设置      │
│ 🔁 重复        不重复      │
│ 📁 清单        收件箱      │
│ 🏷 标签        添加        │
│ 📍 地点        添加        │
│                          │
│ 添加备注                  │
└──────────────────────────┘
```

规则：

- 进入页面后自动聚焦标题。
- 标题非空即可保存。
- 默认清单为收件箱。
- 默认优先级为中。
- 默认无日期、无提醒、不重复。
- 保存失败保留所有输入。
- 重复点击保存由请求幂等机制保护。

开启提醒时：

1. 必须先设置日期和具体时间。
2. 截止不足 10 分钟时不允许开启，并解释原因。
3. 用户点击保存后调用微信订阅授权。
4. 用户拒绝授权时继续保存任务，并显示“未开启微信提醒”。

## 6. 任务详情与编辑

页面分区：

- 标题和完成状态。
- 日期与时间。
- 提醒状态。
- 重复规则。
- 优先级。
- 清单。
- 标签。
- 地点。
- 备注。
- 删除入口。

编辑重复任务时，在保存前弹出作用范围：

```text
应用修改

○ 仅本次
○ 本次及以后

[取消] [确认]
```

删除重复任务使用相同作用范围选择。

## 7. 重复设置

```text
┌──────────────────────────┐
│ 重复设置                  │
│                          │
│ ○ 每天                    │
│ ● 每周                    │
│ ○ 每月                    │
│                          │
│ 一 二 三 四 五 六 日        │
│ ● ○ ● ○ ● ○ ○           │
│                          │
│ 结束：永不结束             │
│                          │
│              确定         │
└──────────────────────────┘
```

每日：

- 每天生成。

每周：

- 至少选择一个星期。
- 默认选择当前截止日期对应的星期。

每月：

- 选择 1～31 日。
- 如果目标月份不存在该日期，明确提示“将在该月最后一天执行”。

结束方式：

- 永不结束。
- 指定结束日期。

## 8. 提醒授权

### 8.1 创建时授权

授权请求只能在用户主动保存时触发。

授权结果：

- 接受：显示“已开启微信提醒”。
- 拒绝：显示“任务已保存，微信提醒未开启”。
- 禁止或模板不可用：显示设置引导或服务暂不可用提示。

### 8.2 重复任务补充授权

首页在需要授权时显示非阻塞横幅：

```text
有 3 个重复待办需要补充提醒授权    去开启
```

- 用户点击“去开启”后才调用微信授权。
- 横幅可以关闭。
- 不在应用启动时自动弹出微信授权。
- 服务端记录的剩余机会仅作为提示依据，不向用户承诺精确数量。

## 9. 清单页

```text
┌──────────────────────────┐
│ 清单                    ＋ │
│                          │
│ 收件箱                 12  │
│ 工作                    6  │
│ 学习                    4  │
│ 生活                    8  │
│                          │
│ 标签管理                  │
│ [重要] [外出] [采购]       │
│                          │
│ 待办        清单       我的 │
└──────────────────────────┘
```

### 9.1 清单操作

- 点击清单：查看该清单的待办。
- 点击“+”：新建清单。
- 左滑自定义清单：重命名或删除。
- 收件箱不能重命名或删除。
- 删除清单前提示其中任务将移入收件箱。

### 9.2 标签管理

- 创建、重命名和删除标签。
- 删除前提示只解除关联，不删除任务。
- 标签名称最多 10 字。
- 单个任务最多选择 5 个标签。

## 10. 地点

地点选择弹层：

```text
添加地点

[从地图选择]
[手动输入]
```

地图能力可用：

- 调用 `wx.chooseLocation`。
- 返回地点名称、地址和 GCJ-02 经纬度。

地图能力不可用或申请失败：

- 不显示“从地图选择”。
- 保留“手动输入”。
- 已有手动地点功能不受影响。

用户拒绝位置权限：

- 解释权限用途。
- 提供打开设置入口。
- 始终允许改用手动输入。

## 11. 回收站

列表展示：

- 标题。
- 删除日期。
- 剩余保留天数。
- 原完成状态。

操作：

- 恢复。
- 永久删除。
- 清空回收站。

永久删除和清空回收站必须二次确认。恢复后：

- 原清单仍存在时恢复到原清单。
- 原清单已删除时恢复到收件箱。

```text
┌──────────────────────────┐
│ 今日待办                  │
│ 我的 · 数据与账号          │
│                          │
│ [今] 今日待办              │
│     微信账号已安全登录      │
│                          │
│ 数据                      │
│ 本周回顾              ›   │
│ 立即同步              ›   │
│ 回收站         保留30天 ›  │
│                          │
│ 账号                      │
│ 注销账号              ›   │
│                          │
│ 待办        清单       我的 │
└──────────────────────────┘
```

昵称和头像是可选项。没有授权时使用默认头像和「微信用户」或产品占位文案。

「本周回顾」进入独立子页（§12.1）。

注销流程：

1. 展示将删除的数据范围（含周报记录）。
2. 要求勾选确认。
3. 二次确认。
4. 提交后立即退出并清除本地缓存。
5. 不提供继续访问原数据的入口。

### 12.1 本周回顾

完整产品规则见 [`WEEKLY_REVIEW_MVP.md`](./WEEKLY_REVIEW_MVP.md)。

```text
┌──────────────────────────┐
│ 本周回顾                  │
│ [本周] [上周]              │
│ 8月18日 – 8月24日 · 完整周 │
│                          │
│ 安排 12  完成 8  逾期 2    │
│ 高优完成率 67%  最忙 周三   │
│                          │
│ —— 以下仅 AI 可用时 ——     │
│ 摘要 …                    │
│ 需要改进                   │
│ · 高优未闭环 …        ›   │
│ · 单日过载 …          ›   │
│ [重新生成]                │
└──────────────────────────┘
```

交互要点：

- 周切换至少支持本周 / 上周。
- AI 未开放（本周且周日 19:00 前）：只显示统计 + 说明「周日 19:00 后可生成周报」，隐藏摘要/改进/生成按钮的模型态（或按钮禁用并解释）。
- AI 已开放且无结果：主按钮「生成周报」。
- 生成中：按钮 loading；允许返回「我的」后再进入。
- 改进条可点击跳转任务编辑；任务不存在则 toast。
- 降级为规则结果时，用次要文案标明「规则分析」以免与模型结果混淆。

## 13. 页面状态

### 13.1 加载

- 首屏优先展示本地缓存。
- 同步时使用轻量顶部状态，不用全屏遮挡已有内容。
- 没有缓存时显示骨架屏。
- 本周回顾统计优先快速返回；AI 生成单独 loading。

### 13.2 空状态

待办为空：

```text
今天还没有安排，先写下第一件事
```

回收站为空：

```text
回收站是空的
删除的待办会在这里保留 30 天
```

本周回顾无安排：

```text
这一周还没有记录的安排
```

### 13.3 错误

- 使用用户可理解的说明。
- 提供重试入口。
- 不显示内部错误码或异常栈。
- 用户填写的表单内容不丢失。
- 周报生成失败时保留统计区并提供重试。

### 13.4 离线

- 顶部显示“当前为离线内容”和待同步数量。
- 已缓存任务正常展示。
- 创建、编辑、完成、删除可操作，操作显示“离线修改将排队，恢复网络后同步”。
- 顶部待同步数量随操作实时更新。
- 网络恢复后自动回放同步。
- 本周回顾的「生成周报」依赖网络；离线时禁用并说明。

## 14. 无障碍与可用性

- 所有图标提供文字语义。
- 颜色不是唯一状态信号。
- 完成按钮、浮动按钮和列表操作有足够点击区域。
- 正文和背景保持清晰对比。
- 系统字体放大时允许卡片高度增长。
- 滑动操作必须有详情页中的等价按钮，避免只能通过手势完成。
- 关键确认弹窗的主要和危险操作位置保持一致。

## 15. 原型验收路径

在实现高保真视觉前，低保真原型必须走通：

1. 创建一条只有标题的任务。
2. 创建一条有日期、提醒、地点和标签的任务。
3. 创建每周重复任务。
4. 完成任务并在 5 秒内撤销。
5. 删除任务并从回收站恢复。
6. 修改重复任务的“本次及以后”。
7. 拒绝订阅授权后继续保存任务。
8. 拒绝位置权限后改用手动地点。
9. 在离线状态查看缓存并确认无法修改。
10. 注销并确认本地数据被清除。
11. 打开本周回顾：周日 19:00 前本周仅统计；之后可生成 AI；无 Key 时规则降级。
12. 从改进项进入仍存在的任务详情。
