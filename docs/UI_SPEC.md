# 今日待办：页面与交互规格

| 项目 | 内容 |
| --- | --- |
| 版本 | 1.0 |
| 状态 | 已确认 |
| 确认日期 | 2026-07-31 |
| 风格 | 大留白、圆角卡片、清爽蓝 |

本文继承 [`PRD.md`](./PRD.md) 的信息架构和产品规则；如交互方案改变产品行为，应先更新 PRD，再同步本文。

## 1. 设计原则

- 首页优先回答“今天要做什么”。
- 创建简单待办只要求输入标题。
- 高级字段按需展开，不阻塞快速创建。
- 状态主要通过文字、图标和小面积色彩表达，不使用大面积警示色。
- 所有页面都提供加载、空、错误和离线状态。
- 支持系统字体放大，核心内容不依赖固定高度。
- 点击区域不小于微信小程序建议的可操作尺寸。
- 动画只用于反馈状态变化，不影响完成任务。

## 2. 设计令牌

### 2.1 色彩

| 用途 | 色值 |
| --- | --- |
| 主色 | `#2563EB` |
| 主色浅背景 | `#EFF6FF` |
| 页面背景 | `#F7F8FA` |
| 卡片背景 | `#FFFFFF` |
| 主文字 | `#1F2937` |
| 次文字 | `#6B7280` |
| 弱文字 | `#9CA3AF` |
| 边框 | `#E5E7EB` |
| 危险 | `#DC2626` |
| 成功 | `#16A34A` |
| 警告 | `#D97706` |

优先级：

- 高：红色小圆点或短竖条。
- 中：橙色小圆点或短竖条。
- 低：蓝灰色小圆点或短竖条。

禁止仅依靠颜色传达完成、错误或优先级；同时使用文字或图标。

### 2.2 尺寸

- 页面水平边距：16px。
- 卡片间距：12px。
- 卡片内边距：16px。
- 卡片圆角：16px。
- 按钮圆角：12px。
- 标签圆角：8px。
- 浮动创建按钮：56px。
- 图标与文字间距：8px。

### 2.3 层级

- 页面背景使用浅灰。
- 主内容卡片使用白色。
- 卡片优先使用浅边框；阴影只用于浮动按钮和弹层。
- 不使用复杂渐变。

## 3. 全局导航

底部导航：

1. 待办。
2. 清单。
3. 我的。

“新建待办”不是独立 Tab，通过待办首页右下角浮动按钮进入。

### 4.2 页面组成

- 顶部：产品名称、日期、筛选入口。
- 快捷筛选：全部、高优先级、标签。
- 分组：逾期、今天、以后、无日期。
- 浮动按钮：新建待办。
- 底部导航。

空分组不显示。全部分组为空时显示整体空状态。

### 4.3 任务卡片

任务卡片包含：

- 左侧圆形完成按钮。
- 标题，最多显示两行。
- 清单、标签或地点摘要。
- 右侧截止时间。
- 重复图标。
- 提醒状态图标。
- 优先级小标记。

交互：

- 点击卡片：进入任务详情。
- 点击完成按钮：立即完成并提供 5 秒撤销。
- 左滑：显示“编辑”和“删除”。
- 长按：首版无操作。

完成任务时卡片淡出当前分组，不使用耗时的庆祝动画。

### 4.4 筛选

筛选弹层包含：

- 清单。
- 标签。
- 优先级。
- 是否有日期。
- 是否有地点。

多个条件之间采用“同时满足”，多个标签之间采用“包含任意所选标签”。清除筛选后回到全部。

## 5. 快速创建

```text
┌──────────────────────────┐
│ 新建待办              保存 │
│                          │
│ 需要做什么？              │
│ ──────────────────────── │
│                          │
│ 📅 日期        未设置      │
│ ⏰ 时间与提醒   未设置      │
│ 🔁 重复        不重复      │
│ 📁 清单        收件箱      │
│ 🏷 标签        添加        │
│ 📍 地点        添加        │
│                          │
│ 添加备注                  │
└──────────────────────────┘
```

规则：

- 进入页面后自动聚焦标题。
- 标题非空即可保存。
- 默认清单为收件箱。
- 默认优先级为中。
- 默认无日期、无提醒、不重复。
- 保存失败保留所有输入。
- 重复点击保存由请求幂等机制保护。

开启提醒时：

1. 必须先设置日期和具体时间。
2. 截止不足 10 分钟时不允许开启，并解释原因。
3. 用户点击保存后调用微信订阅授权。
4. 用户拒绝授权时继续保存任务，并显示“未开启微信提醒”。

## 6. 任务详情与编辑

页面分区：

- 标题和完成状态。
- 日期与时间。
- 提醒状态。
- 重复规则。
- 优先级。
- 清单。
- 标签。
- 地点。
- 备注。
- 删除入口。

编辑重复任务时，在保存前弹出作用范围：

```text
应用修改

○ 仅本次
○ 本次及以后

[取消] [确认]
```

删除重复任务使用相同作用范围选择。

## 7. 重复设置

```text
┌──────────────────────────┐
│ 重复设置                  │
│                          │
│ ○ 每天                    │
│ ● 每周                    │
│ ○ 每月                    │
│                          │
│ 一 二 三 四 五 六 日        │
│ ● ○ ● ○ ● ○ ○           │
│                          │
│ 结束：永不结束             │
│                          │
│              确定         │
└──────────────────────────┘
```

每日：

- 每天生成。

每周：

- 至少选择一个星期。
- 默认选择当前截止日期对应的星期。

每月：

- 选择 1～31 日。
- 如果目标月份不存在该日期，明确提示“将在该月最后一天执行”。

结束方式：

- 永不结束。
- 指定结束日期。

## 8. 提醒授权

### 8.1 创建时授权

授权请求只能在用户主动保存时触发。

授权结果：

- 接受：显示“已开启微信提醒”。
- 拒绝：显示“任务已保存，微信提醒未开启”。
- 禁止或模板不可用：显示设置引导或服务暂不可用提示。

### 8.2 重复任务补充授权

首页在需要授权时显示非阻塞横幅：

```text
有 3 个重复待办需要补充提醒授权    去开启
```

- 用户点击“去开启”后才调用微信授权。
- 横幅可以关闭。
- 不在应用启动时自动弹出微信授权。
- 服务端记录的剩余机会仅作为提示依据，不向用户承诺精确数量。

## 9. 清单页

```text
┌──────────────────────────┐
│ 清单                    ＋ │
│                          │
│ 收件箱                 12  │
│ 工作                    6  │
│ 学习                    4  │
│ 生活                    8  │
│                          │
│ 标签管理                  │
│ [重要] [外出] [采购]       │
│                          │
│ 待办        清单       我的 │
└──────────────────────────┘
```

### 9.1 清单操作

- 点击清单：查看该清单的待办。
- 点击“+”：新建清单。
- 左滑自定义清单：重命名或删除。
- 收件箱不能重命名或删除。
- 删除清单前提示其中任务将移入收件箱。

### 9.2 标签管理

- 创建、重命名和删除标签。
- 删除前提示只解除关联，不删除任务。
- 标签名称最多 10 字。
- 单个任务最多选择 5 个标签。

## 10. 地点

地点选择弹层：

```text
添加地点

[从地图选择]
[手动输入]
```

地图能力可用：

- 调用 `wx.chooseLocation`。
- 返回地点名称、地址和 GCJ-02 经纬度。

地图能力不可用或申请失败：

- 不显示“从地图选择”。
- 保留“手动输入”。
- 已有手动地点功能不受影响。

用户拒绝位置权限：

- 解释权限用途。
- 提供打开设置入口。
- 始终允许改用手动输入。

## 11. 回收站

列表展示：

- 标题。
- 删除日期。
- 剩余保留天数。
- 原完成状态。

操作：

- 恢复。
- 永久删除。
- 清空回收站。

永久删除和清空回收站必须二次确认。恢复后：

- 原清单仍存在时恢复到原清单。
- 原清单已删除时恢复到收件箱。

```text
└──────────────────────────┘
```

昵称和头像是可选项。没有授权时使用默认头像和“微信用户”。

注销流程：

1. 展示将删除的数据范围。
2. 要求勾选确认。
3. 二次确认。
4. 提交后立即退出并清除本地缓存。
5. 不提供继续访问原数据的入口。

## 13. 页面状态

### 13.1 加载

- 首屏优先展示本地缓存。
- 同步时使用轻量顶部状态，不用全屏遮挡已有内容。
- 没有缓存时显示骨架屏。

### 13.2 空状态

待办为空：

```text
今天还没有待办
点击“+”记录第一件事
```

回收站为空：

```text
回收站是空的
删除的待办会在这里保留 30 天
```

### 13.3 错误

- 使用用户可理解的说明。
- 提供重试入口。
- 不显示内部错误码或异常栈。
- 用户填写的表单内容不丢失。

### 13.4 离线

- 顶部显示“当前为离线内容”和待同步数量。
- 已缓存任务正常展示。
- 创建、编辑、完成、删除可操作，操作显示“离线修改将排队，恢复网络后同步”。
- 顶部待同步数量随操作实时更新。
- 网络恢复后自动回放同步。

## 14. 无障碍与可用性

- 所有图标提供文字语义。
- 颜色不是唯一状态信号。
- 完成按钮、浮动按钮和列表操作有足够点击区域。
- 正文和背景保持清晰对比。
- 系统字体放大时允许卡片高度增长。
- 滑动操作必须有详情页中的等价按钮，避免只能通过手势完成。
- 关键确认弹窗的主要和危险操作位置保持一致。

## 15. 原型验收路径

在实现高保真视觉前，低保真原型必须走通：

1. 创建一条只有标题的任务。
2. 创建一条有日期、提醒、地点和标签的任务。
3. 创建每周重复任务。
4. 完成任务并在 5 秒内撤销。
5. 删除任务并从回收站恢复。
6. 修改重复任务的“本次及以后”。
7. 拒绝订阅授权后继续保存任务。
8. 拒绝位置权限后改用手动地点。
9. 在离线状态查看缓存并确认无法修改。
10. 注销并确认本地数据被清除。
