# 今日待办：产品需求文档

| 项目 | 内容 |
| --- | --- |
| 版本 | 1.0 |
| 状态 | 已确认 |
| 确认日期 | 2026-07-31 |
| 产品形态 | 微信小程序 |
| 目标用户 | 个人用户 |

## 1. 产品概述

“今日待办”是一款面向个人用户的微信小程序，用于快速记录、安排、提醒和完成个人待办事项。

产品核心价值：

> 用户打开小程序后，可以立即知道今天需要处理什么，并以尽可能少的步骤完成记录和管理。

## 2. 产品目标

### 2.1 用户目标

- 熟悉产品后，可在 10 秒内创建一条简单待办。
- 清楚区分逾期、今天、以后和无日期任务。
- 在具备有效微信订阅授权时，获得截止前约 10 分钟的提醒。
- 通过清单、标签和地点整理任务。
- 在不同微信设备上同步数据。

### 2.2 产品观测指标

产品只统计行为，不采集待办内容：

- 首次创建待办完成率。
- 每周创建待办人数。
- 待办完成率。
- 提醒开启率。
- 提醒发送成功率。
- 7 日活跃率。
- API 和页面错误率。

第一版上线后先建立数据基线，不预设未经数据验证的增长目标。

## 3. 目标用户

主要用户：

- 有日常任务管理需求的个人。
- 希望直接在微信中管理轻量事项、不愿安装独立 App 的用户。
- 需要混合管理工作、学习和生活事项的用户。

第一版不服务：

- 家庭共享用户。
- 企业和团队。
- 项目协作团队。
- 需要专业项目管理能力的用户。

## 4. MVP 范围

### 4.1 包含

- 微信静默登录，不强制绑定手机号。
- 创建、查看、编辑、完成、恢复和删除待办。
- 截止日期和时间。
- 截止前约 10 分钟的微信订阅消息提醒。
- 高、中、低优先级。
- 自定义清单。
- 自定义标签。
- 地图选点和手动地点。
- 每天、每周、每月重复。
- 逾期、今天、以后、无日期分组。
- 已完成记录。
- 保留 30 天的回收站。
- 云端同步。
- 账号注销及数据删除。
- 不包含用户内容的基础行为统计和错误日志。

### 4.2 不包含

- 多人协作。
- 子任务。
- 附件。
- 评论和聊天。
- 到达地点自动提醒。
- 数据导出。
- AI 规划。
- 会员和支付。
- PC 端。
- 深色模式。
- 手动拖拽排序。
- 批量操作。
- 复杂运营后台。

## 5. 信息架构

底部导航包含三个入口。

### 5.1 待办

- 全部。
- 逾期。
- 今天。
- 以后。
- 无日期。
- 已完成。
- 标签和清单筛选。
- 高优先级筛选。

### 5.2 清单

- 收件箱。
- 用户创建的清单。
- 清单新建、重命名和删除。
- 标签管理。

### 5.3 我的

- 微信头像和昵称，可选。
- 默认提醒设置。
- 隐私政策。
- 用户协议。
- 意见反馈。
- 回收站。
- 清除已完成。
- 注销账号。

## 6. 核心用户流程

### 6.1 创建待办

1. 用户点击首页右下角的“+”。
2. 输入标题。
3. 可选填写备注、日期、时间、优先级、清单、标签、地点和重复规则。
4. 如开启提醒，由用户点击保存动作触发微信订阅授权。
5. 保存成功。
6. 返回首页，并将任务放入对应分组。

标题是唯一必填项。

### 6.2 完成待办

1. 用户点击任务左侧的圆形勾选框。
2. 任务显示完成反馈。
3. 页面底部显示 5 秒“撤销”入口。
4. 未撤销则进入已完成列表。

### 6.3 删除待办

1. 用户左滑任务。
2. 点击“删除”。
3. 任务进入回收站。
4. 30 天内可以恢复。
5. 到期后永久删除。

### 6.4 编辑重复待办

修改或删除重复任务时，用户必须选择：

- 仅本次。
- 本次及以后。

历史实例和已完成实例不被追溯修改。

## 7. 待办字段

| 字段 | 规则 |
| --- | --- |
| 标题 | 必填，1～100 字 |
| 备注 | 可选，最多 1000 字 |
| 截止日期 | 可选 |
| 截止时间 | 选择日期后可选 |
| 提醒 | 需要具体日期和时间 |
| 优先级 | 高、中、低，默认中 |
| 清单 | 默认“收件箱” |
| 标签 | 每条最多 5 个 |
| 地点 | 每条最多 1 个 |
| 重复 | 不重复、每天、每周、每月 |
| 状态 | 待处理、已完成、回收站 |

用户级限制：

- 最多 50 个清单。
- 最多 100 个标签。
- 标签名称最多 10 字。
- 清单名称最多 20 字。

## 8. 首页规则

首页按以下顺序分组：

1. 逾期任务。
2. 今天任务。
3. 以后任务。
4. 无日期任务。

同一分组内按以下顺序排序：

1. 截止时间升序。
2. 优先级从高到低。
3. 创建时间从新到旧。

任务卡片交互：

- 点击任务进入详情。
- 点击勾选框完成。
- 左滑显示“编辑”和“删除”。
- 点击“+”快速创建。
- 不支持手动拖拽排序。

“逾期”是根据待办状态和截止时间动态计算的展示状态，不是独立持久状态。

## 9. 清单和标签

### 9.1 清单

- 系统自动创建“收件箱”。
- 收件箱不可重命名或删除。
- 用户可以创建、重命名和删除其他清单。
- 删除清单时，其中的任务全部移动到收件箱。
- 删除清单不会删除待办。

### 9.2 标签

- 用户可以创建、重命名和删除标签。
- 删除标签只解除任务关联。
- 删除标签不会删除待办。
- 标签以低饱和色块显示。

## 10. 地点

地点支持：

- 微信地图选点。
- 手动输入地点名称。

地图地点保存：

- 地点名称。
- 地址。
- 纬度。
- 经度。

产品不会：

- 持续获取用户位置。
- 在后台追踪用户。
- 到达地点后自动提醒。

用户拒绝位置权限时，仍可手动输入地点。

微信 `wx.chooseLocation` 仅向与地理位置强相关的场景开放。如果接口申请未通过，第一版降级为只提供手动地点，不阻塞产品上线。

## 11. 重复任务

支持：

- 每天。
- 每周，可选择一个或多个星期。
- 每月，可选择日期。
- 永不结束。
- 指定结束日期。

采用独立实例模型：

- 系统按周期生成新的任务实例。
- 上一次未完成不阻止下一次生成。
- 历史未完成实例继续显示为逾期。
- 每个实例可以独立完成或删除。
- 修改“本次及以后”不会改变历史实例。
- 同一周期只生成一个实例。
- 每月指定日期在目标月份不存在时，使用该月最后一天。

## 12. 提醒

- 固定在截止前约 10 分钟提醒。
- 只有设置了具体日期和时间的任务才能开启提醒。
- 创建时距离截止不足 10 分钟，不提供订阅提醒。
- 用户拒绝授权时，任务仍然正常保存。
- 完成、删除或取消提醒后不再发送。
- 业务时区固定为 `Asia/Shanghai`。
- 提醒发送失败不影响待办本身。

### 12.1 微信平台约束

- 订阅授权必须由用户点击行为触发。
- 一次性订阅的每次接受只提供有限的消息发送机会。
- 重复任务不能假设一次授权后可以永久提醒。
- 首页可以提示用户为后续重复实例补充提醒授权。
- 不在小程序启动时强制请求订阅授权。
- 提醒模板必须通过微信后台审核。

由于阿里云定时触发器采用分钟级扫描，实际发送时间允许落在截止前约 9～10 分钟。

## 13. 账号

### 13.1 登录

- 使用微信 `wx.login` 获取临时登录凭证。
- 服务端使用临时凭证换取微信用户标识。
- 服务端建立自己的登录会话。
- 不强制绑定手机号。
- 昵称和头像可选。
- 微信 `session_key` 不返回小程序端。

### 13.2 注销

1. 用户阅读注销影响。
2. 用户二次确认。
3. 账号立即退出，所有会话立即失效。
4. 原数据立即不可访问。
5. 服务端在 7 天内永久删除用户资料和业务数据。
6. 不含待办内容的安全日志最多保留 180 天。
7. 用户再次进入时视为新账号。

## 14. 无网络和异常处理

### 14.1 无网络

- 可以查看最近一次成功加载的缓存。
- 允许创建、编辑、完成或删除，修改写入待同步队列并显示待同步数量。
- 明确显示“当前为离线内容”和待同步数量。
- 网络恢复后自动回放同步。

### 14.2 保存失败

- 保留当前填写内容。
- 显示用户可理解的错误信息。
- 提供重新提交。
- 使用幂等机制避免重复创建。

### 14.3 登录失效

- 自动尝试重新登录一次。
- 并发请求共享同一次重新登录过程。
- 仍然失败时提示用户重试。
- 不清除本地待提交内容。

### 14.4 提醒失败

- 不影响任务本身。
- 记录脱敏后的失败原因。
- 在任务详情中显示提醒状态。

- 大留白。

- 圆角卡片。
- 清爽蓝主色。
- 深灰正文。
- 低饱和状态色。
- 少量轻阴影。

## 16. 数据统计

允许记录：

- 创建待办。
- 完成待办。
- 设置提醒。
- 创建清单。
- 创建标签。
- 提醒发送成功或失败。
- 页面错误和 API 错误。

禁止采集：

- 待办标题。
- 备注内容。
- 地点名称和地址。
- 标签名称。
- 清单名称。

## 17. 上线依赖

已具备：

- 阿里云账号。
- 微信小程序 AppID。
- 使用中国大陆地域的决策。

正式上线前需要完成：

- 注册或准备域名。
- ICP 备案。
- HTTPS 证书。
- 微信合法请求域名配置。
- 小程序服务类目确认。
- 订阅消息模板审核。
- 地点接口权限申请；申请失败时使用手动地点。
- 隐私保护指引。
- 用户协议和隐私政策。

## 18. 核心验收标准

- 用户首次进入能够完成静默登录。
- 用户只输入标题即可创建任务。
- 熟悉产品的用户可以在 10 秒内完成简单任务创建。
- 任务正确进入逾期、今天、以后或无日期分组。
- 完成任务后可以在 5 秒内撤销。
- 删除任务后可以从回收站恢复。
- 回收站任务在 30 天后永久删除。
- 删除清单不会删除任务。
- 拒绝位置权限后仍可手动填写地点。
- 地点接口未获批准时，产品可仅使用手动地点上线。
- 重复任务按周期生成独立实例。
- 未完成实例不会阻止下一实例生成。
- 月份缺少指定日期时使用月末日期。
- 提醒只在具备有效授权且满足时间条件时发送。
- 用户数据之间完全隔离。
- 注销后用户无法访问原数据。
- 统计事件不包含用户输入的业务内容。
- 无网络时修改进入待同步队列并明确标识，不会静默丢失；恢复网络后自动回放。
