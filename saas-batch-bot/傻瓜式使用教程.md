# 讯灵批量发布机器人 · 傻瓜式使用教程

> 给完全不懂编程的运维同学  
> 你只需要会：打开文件夹、复制粘贴、用 Excel 填表、双击文件

---

## 你要先有什么

1. 一台 Windows 电脑（公司常用电脑即可）
2. 能打开讯灵网站：https://v3.xunlingai.com
3. 研发已经帮你装好本工具的电脑（如果还没装，把本教程第一节给研发/IT）

> 如果你电脑上还不能用，先让会装软件的同事做完「第一节」，你从「第二节」开始即可。

---

## 第一节：让电脑能跑起来（不会就找 IT / 研发）

### 1. 安装 Node.js（只装一次）

1. 打开浏览器，搜索并下载 **Node.js LTS**（官网：https://nodejs.org ）
2. 一路点「下一步」安装
3. 安装完成后，按 `Win + R`，输入 `cmd`，回车
4. 在黑窗口里输入下面这行，再回车：

```text
node -v
```

5. 如果出现类似 `v20.x.x`，说明安装成功

### 2. 打开项目文件夹

找到这个文件夹：

```text
saas-batch-bot
```

### 3. 双击运行「一键安装.bat」

- 双击 `一键安装.bat`
- 等待黑窗口自己跑完（可能要几分钟）
- 看到“安装完成”后，按任意键关闭

如果双击没反应：右键 → 用管理员身份运行。

---

## 第二节：填写账号表（运维每次都可能要改）

### 1. 打开账号表

进入文件夹：

```text
saas-batch-bot\data
```

- 如果还没有 `accounts.csv`  
  就把 `accounts.example.csv` **复制一份**，改名为：`accounts.csv`

### 2. 用 Excel / WPS 打开 `accounts.csv`

按下面格式填写（一行一个账号）：

| id | username | password | enabled | note |
|----|----------|----------|---------|------|
| 1 | 账号A | 密码A | true | 南通店 |
| 2 | 账号B | 密码B | true | 测试号 |
| 3 | 账号C | 密码C | false | 先不用这个号 |

说明（看这一段就够）：

- `username`：讯灵登录账号  
- `password`：讯灵密码  
- `enabled`：填 `true` 表示要用；填 `false` 表示跳过  
- 填完后 **保存并关闭** Excel（很重要，不关闭可能被占用）

## 第三节：开始使用（从这里起都是运维自己操作）

### 方法一：双击菜单（推荐）

1. 回到文件夹 `saas-batch-bot`
2. 双击 `开始使用.bat`
3. 按屏幕提示输入数字选择：

```text
1 = 演练（最安全，不会真的发布）
2 = 正式发布（会真的点发布）
3 = 只补跑失败账号
4 = 查看有哪些点击方案
5 = 退出
```

4. 再按提示选择方案，例如：

```text
1 = 第三方新闻媒体（默认）
2 = 第三方商业媒体
3 = 新闻媒体-每号发3个任务
```

5. 再输入本次要跑几个账号，例如先填 `1` 或 `5`
6. 回车后，电脑会自己打开浏览器开始点

> 第一次请一定先选「1 演练」！

---

### 方法二：复制命令（也可以）

1. 在 `saas-batch-bot` 文件夹空白处  
   按住 `Shift` + 右键 → 选择「在此处打开 PowerShell 窗口」或「打开命令窗口」
2. 复制下面某一条，粘贴，回车

**先演练 1 个账号（推荐第一次就用这个）：**

```text
npm start -- --scheme news-unpublished --limit 1 --dry-run
```

**演练没问题后，正式跑 5 个账号：**

```text
npm start -- --scheme news-unpublished --limit 5
```

**换成商业媒体：**

```text
npm start -- --scheme business-unpublished --limit 5
```

**只补上次失败的账号：**

```text
npm start -- --only-failed
```

## 第四节：怎么判断有没有成功

打开文件夹：

```text
saas-batch-bot\output
```

看这两个文件：

1. `results-latest.csv`（用 Excel 打开）
2. `failed-latest.csv`（失败账号）

在 `results-latest.csv` 里看 `status` 列：

| 显示 | 意思 | 你要做什么 |
|------|------|-----------|
| success | 成功发布了 | 不用管 |
| dry-run | 演练成功 | 可以开始正式跑 |
| skipped | 这个号没有可发内容 | 换方案或换账号 |
| failed | 失败了 | 看 message 列原因，或执行“补跑失败账号” |

---

## 第五节：你最常用的 4 种情况

### 情况 A：我今天要发「新闻媒体」

1. 双击 `开始使用.bat`
2. 先选 `1` 演练
3. 方案选 `1`（新闻媒体）
4. 账号数先填 `1`
5. 演练成功后，再选 `2` 正式发布，账号数填 `5` 或更多

### 情况 B：我今天要发「商业媒体」

同上，方案选 `2`

### 情况 C：我只想先试 1 个号

账号数一律填 `1`

### 情况 D：刚才有几个号失败了

双击 `开始使用.bat` → 选 `3`（补跑失败账号）

## 第六节：想改“每次点几个”怎么办

### 临时改（推荐，不用改文件）

双击菜单后，按提示输入；  
或者让会复制命令的同事帮你改数字：

```text
npm start -- --scheme news-unpublished --tasks 2 --articles 3 --limit 5
```

含义：

- `--tasks 2`：每个账号处理 2 个任务  
- `--articles 3`：每个任务勾 3 篇文章  
- `--limit 5`：这次只跑 5 个账号  

### 长期改（固定成自己的方案）

让研发帮你改 `config\default.json` 里的 `schemes`，  
或者你照着 `运维使用手册.md` 复制一段方案改名字。

## 第七节：常见问题（先看这里）

### 1）双击 bat 一闪就关了

- 右键 bat → 编辑，看是不是被杀毒软件拦截  
- 或右键 → 以管理员身份运行  
- 或把整个 `saas-batch-bot` 文件夹加到杀毒软件白名单

### 2）提示找不到 accounts.csv

去 `data` 文件夹检查：

- 是否有 `accounts.csv`
- 名字有没有多余空格
- 扩展名是不是 `.csv`

### 3）提示密码错误

- 用浏览器手动登录 https://v3.xunlingai.com/#/sign 确认账号密码
- 再回 Excel 改正并保存

### 4）演练成功，正式跑却提示没有任务

说明这个账号在当前方案下没有“未发布”内容。  
试试换「商业媒体」方案，或换有库存的账号。

### 5）浏览器弹出来但自己不动

- 不要手动乱点页面
- 等它自己跑完
- 如果卡住超过 5 分钟，关闭黑窗口，重新演练 1 个号

### 6）中途停电/关掉了怎么办

再运行一次「补跑失败账号」即可。

## 第八节：给运维的“最短口令”

把下面四句发给自己就行：

1. 填好 `data\accounts.csv`  
2. 双击 `开始使用.bat`  
3. 先选「演练」跑 1 个号  
4. 没问题再选「正式发布」

---

## 第九节：不要做的事

- 不要把 `accounts.csv`（含密码）发到微信群/邮箱公开群  
- 不要删除 `auth`、`output` 以外的源码文件夹  
- 不要在机器人运行时手动去点同一个页面抢操作  
- 第一次不要直接全量正式发布，先演练
