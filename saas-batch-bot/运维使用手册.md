# 讯灵批量发布机器人 · 运维使用手册

面向运维/运营人员：按自己的需要选择或配置「点击方案」，批量登录账号并发布文章。

> 完全不懂编程？请先看：**[傻瓜式使用教程.md](./傻瓜式使用教程.md)**  
> Windows 可直接双击：`一键安装.bat` → 填账号 → `开始使用.bat`

---

## 一、第一次准备（只需做一次）

在项目目录执行：

```bash
cd saas-batch-bot
npm install
npx playwright install chromium
cp data/accounts.example.csv data/accounts.csv
```

用 Excel / WPS 打开 `data/accounts.csv`，填入账号：

| id | username | password | enabled | note |
|----|----------|----------|---------|------|
| acc001 | nantongyaao | nt123456 | true | 示例 |
| acc002 | xxx | xxx | true | |

- `enabled=false` 的账号会自动跳过  
- 密码文件只放本机，不要发给别人、不要上传 Git

## 二、点击方案是什么？

「点击方案」= 机器人这次怎么点页面。  
运维只需改配置或命令参数，不用改代码。

默认方案在：`config/default.json` → `schemes`

| 方案名 | 用途 |
|--------|------|
| `news-unpublished` | 第三方新闻媒体，只发未发布任务（默认） |
| `business-unpublished` | 第三方商业媒体，只发未发布任务 |
| `news-batch-3` | 新闻媒体，每号最多发 3 个任务、每任务 3 篇 |
| `selfmedia-unpublished` | 自媒体训练 |
| `web-unpublished` | 智能体官网训练 |

查看全部方案：

```bash
npm start -- --list-schemes
```

## 三、日常怎么跑

### 1）先演练（强烈建议）

只登录、打开任务、勾选文章，**不点最终发布**：

```bash
npm start -- --scheme news-unpublished --limit 1 --dry-run
```

看到日志类似：

```text
dry-run：已勾选 5 篇文章，跳过点击发布
完成：成功/演练 1，失败 0
```

再抽查页面，确认没问题。

### 2）小批量真跑

```bash
npm start -- --scheme news-unpublished --limit 5
```

### 3）全量跑

```bash
npm start -- --scheme news-unpublished
```

### 4）只重跑失败账号

```bash
npm start -- --scheme news-unpublished --only-failed
```

### 5）换商业媒体方案

```bash
npm start -- --scheme business-unpublished --limit 3 --dry-run
npm start -- --scheme business-unpublished --limit 3
```

## 四、按运维需要临时改点击规则（不用改文件）

命令可以直接覆盖方案参数：

```bash
# 指定媒体 Tab + 每号 2 个任务 + 每任务勾 3 篇
npm start -- --media-tab 第三方商业媒体训练 --tasks 2 --articles 3 --limit 1 --dry-run

# 勾选弹窗里当前页全部文章
npm start -- --scheme news-unpublished --all-articles --limit 1 --dry-run

# 不限制“仅未发布”（谨慎）
npm start -- --scheme news-unpublished --include-published --tasks 1 --articles 1 --dry-run
```

参数说明：

| 参数 | 含义 |
|------|------|
| `--scheme` | 选用哪个点击方案 |
| `--media-tab` | 覆盖媒体 Tab 名称 |
| `--tasks` | 每个账号处理几个任务 |
| `--articles` | 每个任务勾几篇文章 |
| `--all-articles` | 勾选弹窗内全部可见文章 |
| `--include-published` | 允许处理已发布过的任务 |
| `--limit` | 本次最多跑几个账号 |
| `--dry-run` | 演练，不最终发布 |
| `--only-failed` | 只跑上次失败账号 |
| `--account acc001` | 只跑指定账号 |

可用媒体 Tab 名称（需与页面按钮文字完全一致）：

- `第三方新闻媒体训练`
- `第三方商业媒体训练`
- `第三方分站训练`
- `自媒体训练`
- `智能体官网训练`

## 五、长期固定方案（改配置文件）

打开 `config/default.json`：

### 1）切换默认方案

```json
"activeScheme": "business-unpublished"
```

之后直接 `npm start` 就会用这个方案。

### 2）新增自己的方案

在 `schemes` 里复制一段改名即可，例如：

```json
"my-ops-plan": {
  "label": "运维自定义-商业媒体每号2任务",
  "mediaTab": "第三方商业媒体训练",
  "maxTasksPerAccount": 2,
  "maxArticlesPerTask": 4,
  "onlyUnpublishedTasks": true,
  "selectMode": "first-n",
  "description": "按运维当天要求自定义"
}
```

然后运行：

```bash
npm start -- --scheme my-ops-plan --limit 2 --dry-run
```

字段说明：

| 字段 | 说明 |
|------|------|
| `mediaTab` | 点哪个媒体类型 Tab |
| `maxTasksPerAccount` | 每个账号点几个任务的「查看发布」 |
| `maxArticlesPerTask` | 每个任务勾几篇文章 |
| `onlyUnpublishedTasks` | `true`=只处理已发布数量为 0 的任务 |
| `selectMode` | `first-n`=按数量勾选；`all-visible`=勾当前可见全部 |

## 六、看结果

运行后打开 `output/`：

- `results-latest.csv`：本次全部结果  
- `failed-latest.csv`：失败账号清单  
- 字段含：账号、状态、勾选数量、失败原因、耗时  

状态含义：

- `success`：已发布  
- `dry-run`：演练成功  
- `skipped`：没有可发任务  
- `failed`：失败（看 message）

---

## 七、推荐操作节奏（100+ 账号）

1. 先 `--limit 1 --dry-run`  
2. 再 `--limit 5` 真跑并人工抽查后台  
3. 确认无误后全量  
4. 用 `--only-failed` 补失败号  
5. 默认一次跑一个账号（最稳）；不要一上来高并发

## 八、常见问题

**Q：演练成功，但真跑提示未找到任务？**  
A：该账号在当前 Tab 下可能没有「已发布=0」的任务。换 `--scheme business-unpublished`，或加 `--include-published`（谨慎）。

**Q：想看浏览器怎么点的？**  
A：保持 `config/default.json` 里 `"headless": false`（默认就是），会弹出浏览器。

**Q：密码错误 / 登录失败？**  
A：检查 `data/accounts.csv` 密码；确认能手动打开 `https://v3.xunlingai.com/#/sign` 登录。

**Q：页面改版按钮文字变了？**  
A：把新的 Tab / 按钮文字告诉研发，或临时用 `--media-tab "新按钮文字"` 试。

**Q：中途停了怎么继续？**  
A：看 `output/failed-latest.csv`，执行 `--only-failed`。

## 九、给运维的最小口令卡

```bash
# 看方案
npm start -- --list-schemes

# 新闻媒体演练 1 个号
npm start -- --scheme news-unpublished --limit 1 --dry-run

# 新闻媒体真跑 5 个号
npm start -- --scheme news-unpublished --limit 5

# 商业媒体真跑
npm start -- --scheme business-unpublished --limit 5

# 临时：商业媒体，每号2任务，每任务3篇
npm start -- --media-tab 第三方商业媒体训练 --tasks 2 --articles 3 --limit 5
```
